Utilizes [ypm](https://github.com/liam8129/youtube-playlist-manager) systems for formatting locally and pushing changes remotely to Youtube. Contributors can not push changes.

### How to contribute:
To help maintain the playlist you can do any of the following:
* Add missing songs 
* Delete privated/deleted videos
* Replace unofficial uploads for official uploads
* Contribute thumbnails for the playlist

Please follow these rules if you are going to contribute:
* Do not add unofficial uploads to the playlist unless there is no official upload
* Do not add UST songs
* Format songs by chronological order, and by variant if possible (if a skin has had multiple themes, they should be next to eachother in chronological order)
